## The entry

> One star. He bought me a luxury bed, then put it in the only corner of the house with no sunbeam. I sleep on his face now.

## How it works

`main.py` (Python standard library only, no network) writes the review line to `/output/entry.txt`. The output is deterministic: every run produces byte-identical output.

```sh
python3 main.py
cat /output/entry.txt
```
